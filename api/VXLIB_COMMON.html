    Common definitions¶

    group Common definitions

    This module consists of definitions (macros, structures, utility functions) that are commonly applicable to all VXLIB kernels.

    Defines¶

    VXLIB_SE_PARAM_SIZE¶

    Parameter structure size in bytes.

    VXLIB_SA_PARAM_SIZE¶

    Parameter structure size in bytes.

    VXLIB_ALIGN_SHIFT_64BYTES¶

    Number of bits to shift for 64-byte memory alignment.

    VXLIB_ALIGN_SHIFT_128BYTES¶

    Number of bits to shift for 128-byte memory alignment.

    VXLIB_ALIGN_SHIFT_256BYTES¶

    Number of bits to shift for 256-byte memory alignment.

    VXLIB_ALIGN_64BYTES¶

    Align by 64-byte memory alignment.

    VXLIB_ALIGN_128BYTES¶

    Align by 128-byte memory alignment.

    VXLIB_ALIGN_256BYTES¶

    Align by 256-byte memory alignment.

    VXLIB_L2DATA_ALIGN_SHIFT¶

    Set the default L2 data alignment.

    VXLIB_L2DATA_ALIGNMENT¶

    Macro that specifies the alignment of data buffers in L2 memory for optimal performance.

    Typedefs¶

    typedef double VXLIB_D64¶

    Double precision floating point.

    typedef float VXLIB_F32¶

    Single precision floating point.

    typedef VXLIB_STATUS_NAME VXLIB_STATUS¶

    Return value for VXLIB functions.

    typedef void *VXLIB_kernelHandle¶

    Handle type for VXLIB operations.

    Enums¶

    enum VXLIB_STATUS_NAME¶

    The enumeration of all status codes.

    Values:

    enumerator VXLIB_SUCCESS¶

    0 => No error

    enumerator VXLIB_ERR_FAILURE¶

    1 => Unspecified error

    enumerator VXLIB_ERR_INVALID_VALUE¶

    2 => Invalid parameter value

    enumerator VXLIB_ERR_INVALID_TYPE¶

    3 => Invalid parameter type (VXLIB_data_type_e data_type)

    enumerator VXLIB_ERR_INVALID_DIMENSION¶

    4 => Dimension parameter (width/height) is too big/small

    enumerator VXLIB_ERR_NULL_POINTER¶

    5 => Unsupported null pointer condition

    enumerator VXLIB_ERR_NOT_IMPLEMENTED¶

    6 => Parameter configuration is not supported/implemented

    enumerator VXLIB_ERR_NOT_EQUAL_WIDTH_STRIDE¶

    7 => Stride should be equal to width * element size

    enumerator VXLIB_ERR_NOT_ALIGNED_PTRS_STRIDES¶

    8 => Pointers and stride values are not aligned to documented value

    enumerator VXLIB_ERR_NOT_ALIGNED_WIDTHS¶

    9 => Width values are not aligned to documented value

    enumerator VXLIB_ERR_BUFFER_TOO_SMALL¶

    10 => Buffer size not large enough

    enumerator VXLIB_ERR_INVALID_ACTIVATION¶

    11 => Activation selection incompatible with data type

    enumerator VXLIB_ERR_INVALID_SHIFT¶

    12 => Requested shift amount is not valid

    enumerator VXLIB_ERROR_MAX¶
    enumerator VXLIB_ERR_CONVOLVE_PADDED_NOT_IMPLEMENTED¶

    1000 => Padded implementation not supported

    enumerator VXLIB_ERR_CONVOLVE_INVALID_TYPE_COMBINATION¶

    1001 => data type combination is not supported

    enumerator VXLIB_ERR_CONVOLVE_INVALID_DIMENSION¶

    1002 => dimension combinations are invalid for given method

    enumerator VXLIB_ERR_CONVOLVE_INVALID_SHIFT¶

    1003 => shift value is out of bounds

    enum VXLIB_FUNCTION_STYLE¶

    Enumeration for the style of function implementation.

    Values:

    enumerator VXLIB_FUNCTION_NATC¶

    Natural C implementation of the function

    enumerator VXLIB_FUNCTION_OPTIMIZED¶

    Optimized C implementation of the function for C7x architecture

    enumerator VXLIB_FUNCTION_MAX¶
    enum VXLIB_OVERFLOW_POLICY¶

    Enumeration for the overflow policy.

    Values:

    enumerator VXLIB_WRAP¶

    Wrap the result of the operation

    enumerator VXLIB_SATURATE¶

    Saturate the result of the operation
